# 高中物理 · 力学模型实验室（3D）

纯前端、可离线运行的高中物理力学 3D 交互实验室，六大经典模型全部内置，
每个模型都有**实时受力分析**（3D 受力箭头 + 2D 受力示意图 + 运动方程 + 状态判断）、
运动图像（x-t / v-t / a-t）和经典考题预设。适合课堂演示与学生自学。

## 六大模型

| 模型 | 核心知识点 |
|---|---|
| 🧊 滑块模型 | 匀变速运动、刹车距离、静/动摩擦 |
| ⛰️ 斜面模型 | 倾角 0–85° 可调、mg sinθ / mg cosθ 正交分解、tanθ = μ 临界角 |
| 🛤️ 传送带模型 | 相对速度决定摩擦力方向、共速、划痕长度（相对位移） |
| 🌀 弹簧振子 | F = −kx、T = 2π√(m/k)、阻尼振动、机械能守恒验证 |
| 🔗 连接体模型 | 整体法 / 隔离法、接触力 N = m(a + μg) |
| ⚙️ 弹簧连接体 | 质心匀速 + 相对简谐运动、约化质量 |

## 功能

- 3D 画面（Three.js）：鼠标拖拽旋转 / 滚轮缩放 / 右键平移，镜头跟随，手机单指旋转双指缩放
- 实时受力分析：彩色受力箭头（重力→蓝、支持力→绿、摩擦力→红、外力→橙、弹力→紫、接触力→青），标注数值
- 斜面模型：倾角滑块 + ±1°/±5° 微调 + 数值输入，3D 扇形角度指示，重力分解虚线可开关
- 运动图像：位移 / 速度 / 加速度 / 相对速度曲线，时间窗口可调
- 实验预设：每模型 4–5 个经典考题场景（临界平衡、逆向传送带等）
- 单步前进 0.05 s、0.25×–2× 慢放快放、能量条形图

## 如何使用

### 方式一：本地打开（离线可用）
下载本仓库，双击 `index.html` 即可（`three.min.js`、`OrbitControls.js` 需同目录）。

### 方式二：GitHub Pages（随时在线，推荐）
1. 登录 github.com → 右上角 **+** → **New repository**
2. Repository name 填 `physics-lab`，选 **Public**，点 **Create repository**
3. 进入仓库 → **Add file → Upload files**，把本仓库 4 个文件全部拖入，点 **Commit changes**
4. 仓库页 **Settings → Pages**：Source 选 **Deploy from a branch**，Branch 选 `main`、目录选 `/ (root)`，点 **Save**
5. 等待约 1 分钟，访问：
   `https://<你的用户名>.github.io/physics-lab/`
6. 把该链接发到微信，随时随地打开使用（无电脑、无隧道限制）

### 手机 / 微信使用提示
- 页面自动竖排：参数面板 → 3D 画面 → 图像 → 受力分析
- 单指拖动旋转视角，双指缩放
- 微信提示"非微信官方网页"时点【继续访问】

## 技术说明
- Three.js r128 本地文件（无需 CDN，离线可用）
- 牛顿力学数值积分：半隐式欧拉，子步 0.002 s，弹簧高频稳定
- 全部物理数值已对照解析解验证（共 25+ 项自动化检查全部通过）
- 纯静态页面，无后端，任意静态托管（GitHub Pages / Gitee Pages / Netlify）直接可用
